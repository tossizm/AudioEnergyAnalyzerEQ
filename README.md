# ClubAudioAnalyzer EQ VST3

A JUCE-based VST3 effect that applies ten RBJ Audio EQ Cookbook Peaking/Bell biquads. It loads two JSON files:

1. **EQ settings JSON** exported by the ClubAudioAnalyzer ratio-EQ result dialog using **「VST3用EQ設定JSONを保存」**. This contains all ten filters (`frequency_hz`, `q`, `gain_db`) and the target ratio metadata.
2. **Ratio reference JSON** generated by ClubAudioAnalyzer. `target_ratio_pct` is preferred; legacy files with ten `target_db` values are also accepted and converted to normalized power ratios.

The reference JSON is used to display the target ratios. It does not synthesize EQ settings by itself: the EQ settings JSON is required to process audio. The plug-in applies the loaded filters to audio in real time and does not alter the source file.

## Build on Windows 11

Requirements:
- Visual Studio 2022 with **Desktop development with C++** workload
- CMake 3.22 or newer
- Git and internet access for the first build (CMake downloads JUCE 8.0.6)

From the project root, run:

```bat
build_vst3_windows.bat
```

or `build_all_windows.bat` to build the desktop app and then the VST3. The VST3 bundle is copied to `dist\VST3\ClubAudioAnalyzer EQ.vst3`.

## Important notes

- This source project is set to JUCE 8.0.6 and VST3 format. A Windows VST3 binary has **not** been built in the Linux authoring environment; run the Windows batch file to produce it.
- Review JUCE's current licensing terms before distributing a built plug-in. JUCE is offered under commercial and open-source licensing terms; choose the license appropriate to your distribution.
- The processor accepts mono/stereo input, preserves the host sample rate, and uses the same RBJ peaking coefficient formula as ClubAudioAnalyzer. It is a real-time EQ effect, not a loudness or ratio analyzer; the offline analyzer is what derives the EQ settings.
